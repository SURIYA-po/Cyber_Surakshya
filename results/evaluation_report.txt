──────────────────────────────────────────────────────────────────────
ZEEK conn.log → CICIDS2017 FEATURE MAPPING
──────────────────────────────────────────────────────────────────────

ZEEK conn.log  →  CICIDS2017 Feature
─────────────────────────────────────────────────────────────
id.resp_p        →  Destination Port
duration         →  Flow Duration  (duration * 1e6 = microseconds)
orig_pkts        →  Total Fwd Packets
resp_pkts        →  Total Backward Packets
orig_bytes       →  Total Length of Fwd Packets
resp_bytes       →  Total Length of Bwd Packets
bytes/duration   →  Flow Bytes/s  (derived)
pkts/duration    →  Flow Packets/s (derived)
history          →  SYN/FIN/RST/PSH/ACK/URG Flag Counts (parsed from history string)
orig_ip_bytes/pkts → Avg Fwd Segment Size (derived)
resp_ip_bytes/pkts → Avg Bwd Segment Size (derived)
(resp_pkts)/(orig_pkts) → Down/Up Ratio (derived)

NOTE: IAT (inter-arrival times), individual packet-length stats, and TCP
window sizes require Zeek zeek-flow-stats scripts or custom analyzers
beyond the default conn.log output.


──────────────────────────────────────────────────────────────────────
DESIGN NOTES FOR ZEEK INTEGRATION
──────────────────────────────────────────────────────────────────────

The selected feature set is designed to maximize coverage from Zeek conn.log.
Features requiring custom Zeek scripts (IAT stats, pkt length stats):
  → Use zeek-flow-stats package or write a custom Zeek policy script
  → For basic IDS with conn.log only, set IAT/pkt-length features = 0
    The model still achieves high accuracy on the remaining features.

Recommended Zeek integration architecture:
  1. Zeek sensor captures traffic and writes conn.log
  2. Python consumer reads conn.log lines in real-time (tail -f / inotify)
  3. translate_zeek_conn_log() maps fields to CICIDS2017 schema
  4. inference.predict() returns attack class + confidence
  5. Alerts sent to SIEM / dashboard for analyst review

False positive considerations:
  - BOTNET class has low precision (0.15) → expect FPs; filter by confidence > 0.7
  - WEBATTACK has moderate precision (0.54) → combine with HTTP log analysis
  - BRUTEFORCE, DDOS, PORTSCAN achieve >0.99 precision → highly reliable
