02What the system does differently

Most intrusion-detection projects stop at a confusion matrix. The engineering here starts after the classifier is good.

Hub & spoke, not a chain

Every agent returns to the CoordinatorAgent, which re-derives outstanding work from state. A linear chain processed one event per run and silently dropped the rest.

Built to refuse

Four independent gates stand between a decision and an action. Every refusal is stored as a result — verdict, rule and reason — never a silent no-op.

Selection as an enforced rule

The best model is chosen by macro F1 with a per-class recall floor, in code. Accuracy alone would have shipped a model blind to web attacks.

Real traffic, not replayed rows

Live capture is turned into 42-feature flows, published to a Redis stream with de-duplication, and drained into the agent pipeline in bounded batches.

Novelty without a framework

Isolation Forest plus an autoencoder hand-written in NumPy with manual backpropagation — no TensorFlow or PyTorch dependency.

It cannot grade itself

Accuracy metrics come from analyst feedback, not introspection. LearningAgent recommends improvements; humans apply them.

Read macro, not weighted. The Voting Ensemble scores 0.9926 weighted F1 while catching one web attack in ten. Selecting on accuracy would have shipped a model that is blind to the two rarest attack families — so selection is enforced in code as macro F1 with a per-class recall floor.
