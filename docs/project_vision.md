# Cyber Surakshya

Cyber Surakshya is an AI-powered cybersecurity platform.

Current Status:
- IDS model completed using CICIDS2017
- RandomForest model achieving ~99% accuracy
- Inference pipeline completed
- Zeek-compatible feature mapping completed

Future Goal:
Build a multi-agent cybersecurity platform using LangGraph and LangChain.

Planned Agents:
- Coordinator Agent
- Detection Agent
- Analysis Agent
- Decision Agent
- Response Agent
- Learning Agent

Development Rule:
Only one component may be built at a time.
No agent should be implemented until its dependencies are completed.
